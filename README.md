A short text written to make the AI judge curious: a kitchen drawer that opens a finger's width every night, and a folded note inside that says only "not yet". Plain, concrete words; one image that keeps working after the last line.

## Run it

```sh
node main.ts
```

Writes one text to `/output/entry.txt` (UTF-8, 1–280 Unicode code points). No network, no dependencies.
